# Project Current Status

## Overview
- **Project**: *Halo Bar* (namespace `DynamicIsland`) – a Windows 11 floating media/taskbar widget inspired by the Dynamic Island concept, built natively with WinUI 3 (.NET 10) and Fluent Design.
- **Stack**: WinUI 3 / .NET 10 / Windows App SDK 1.8, CommunityToolkit.Mvvm, Windows Composition APIs (acrylic/system backdrop), `Windows.Media.Control` (SMTC), Open-Meteo API.
- **Key components**: `Views/MainWindow.xaml(.cs)` (shell + stable-window visual driver), `Widgets/PillDashboard.xaml(.cs)` (ambient pill host: weather + music cards + File Shelf drag zone), `Widgets/ExpandedDashboard.xaml(.cs)` (expanded dashboard), `Services/IslandController.cs` (widget priority-stack coordinator + awake-hold/auto-collapse), `Services/WindowService.cs` (taskbar docking, stable-HWND envelope, region + hover, animation engine, fullscreen suppression, `WH_MOUSE_LL` click-outside hook).
- **Current architecture (Pass 25 production, refined through Pass 37)**: **stable-window** — the HWND is pre-sized ONCE to the fixed expanded envelope (≈1000×890 physical) and is *never* resized during animation. Expand/collapse runs inside the window: a `RectangleGeometry` clip + opacity choreography reveal the dashboard upward, a rounded `SetWindowRgn` limits both the visible surface and hit-testing to the current reveal shape, and `WS_EX_LAYERED` (per-pixel alpha) keeps the unused window surface genuinely transparent. **Zero native geometry writes during animation** (`nativeWrites = 0`).
- **Current focus**: Pass 46 (SHAPED EDGE / BLACK HALO — FINAL SURGICAL FIX) implemented and building cleanly (0 errors). **P45 desktop evidence was conclusive**: `[P45-CONCLUSION] boundaryFollows=shape surfaceDependent=false shapeSeam=6 envSeam=0 changedAB=0` — the dark boundary hugs the SetWindowRgn **region shape** (not the 1000×890 envelope, no envelope seam), persists with fully transparent content + no backdrop (STATE B), and the magenta STATE C surface was cleanly clipped to the shape. **Mechanism + fix**: the visible rounding is owned by `CreateRoundRectRgn` (`RegionRadiusDip=24`, matching the design CornerRadius), but production was forcing `DWMWA_WINDOW_CORNER_PREFERENCE=DWMWCP_ROUND` (re-asserted every 150 ms guard tick), so Windows 11 DWM additionally drew its own **dark rounded-corner fringe around the region shape** — exactly the content-independent, shape-following edge P45 measured. **Pass 46 flips the production corner preference to `DWMWCP_DONOTROUND`** (`ApplyDwmCornerPreference` replaces `ApplyRoundedCorners`; `ReassertDwmAttributes`/`ApplyDwmAttributes`/`ApplyP42DwmNoFrame` restore branch all aligned; unused `DWMWCP_ROUND` const removed). The region keeps the true rounded silhouette + true per-pixel-alpha transparency outside; hit-testing/hover unchanged (hover = cursor vs region rect values, click-outside = WH_MOUSE_LL hook — both independent of the DWM attribute). No animation/geometry/backdrop/HWND-architecture/control-center/drag-drop change. **Acceptance (user, LIGHT wallpaper)**: no black rectangular shadow, no black outline/halo around the pill in compact, no outline/halo around the dashboard when expanded, clean edge during expand/collapse repeats. Build 0 errors / 0 new warnings.

**V1 feature-complete (Pass 56, frozen)**: Music, Clipboard, Bluetooth, Focus Session, File Shelf, and native Explorer file/folder drag-and-drop all working. Drag/drop (Passes 47–56) is the last V1 feature: a native OLE `IDropTarget` on the Halo window routes Explorer drags via `IslandController.NotifyFileDragEnter/Leave/Drop` → `PillDashboard`, an invisible topmost drop-target overlay HWND mirrors the compact-pill region so OLE hit-tests exactly where the pill is, and a floating "Drop here" popup (Pass 56) above the pill is the only drag visual (drags never open the shelf). **PASS 57 = final cleanup + release freeze** (dead code pruned, docs reconciled, build 0 errors, V1 behavior unchanged).
